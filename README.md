# QuizSystem-Project-Using-JAVA

A simple console-based Quiz System built in Java. The application allows users to attempt multiple-choice questions and displays their final score. This project is ideal for learning Java fundamentals such as loops, arrays, user input, and basic OOP concepts.

---

## ✨ Features

- Multiple MCQ questions
- Score calculation
- Console-based UI
- Easy-to-read and modify code
- Beginner-friendly structure
