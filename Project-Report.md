# Project Report – Java Quiz System

## 1. Introduction
This project implements a simple Quiz System using Java. It allows users to answer multiple-choice questions and calculates the final score.

## 2. Objectives
- Understand Java basics
- Implement loops and arrays
- Build an interactive console program

## 3. Features
- Stores quiz questions and answers
- Displays user score
- User-friendly console interface

## 4. Tools Used
- Java (JDK 8+)
- Any IDE (VS Code, IntelliJ, Eclipse) or command line

## 5. Conclusion
This project demonstrates how Java can be used to create small interactive applications.
